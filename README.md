CobVar
A resource of genomic variants associated with vitamin B12 status and related biomarkers.
Overview
CobVar brings together published genetic association findings relevant to vitamin B12 absorption, transport, and metabolism. The project combines literature curation, structured data organization, and a searchable web database to make findings easier to explore across studies.

The published resource contains 324 variant associations, covering 222 unique variants and 84 genes across five traits:
- Total serum or plasma vitamin B12
- Holotranscobalamin
- Total transcobalamin
- Holohaptocorrin
- Methylmalonic acid
The associations were curated from genome-wide association studies and candidate gene studies.
My contributions

- Curating published variant–phenotype associations and organizing study information into a consistent format.
- Designing the database framework and structuring the curated records.
- Developing the MongoDB-backed platform and web interface using PHP, JavaScript, HTML, and CSS.
